# Starch wallpapers

Add wallpaper images anywhere in this directory. The ISO build copies each
image under `/usr/share/wallpapers` for both the live and installed Xfce
desktops.

When present, `wyxina-tree-8559118.jpg` supplies the Evergreen background used
by the Xfce defaults and installed LightDM greeter. Its path in both images is
`/usr/share/wallpapers/Starch-Evergreen/contents/images/3840x2160.jpg`.

Supported filename extensions are AVIF, BMP, GIF, JPEG, JXL, PNG, SVG, TIFF,
and WebP.
